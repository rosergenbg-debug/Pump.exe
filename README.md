# PUMP Research Lab (`Pump.exe`)

Отдельная Windows-лаборатория для причинного тестирования, синтетических прогонов и безопасного обучения адаптивных стратегий проекта PUMP/PumpBot.

Проект не отправляет реальные биржевые ордера. Первая цель — воспроизводимая цепочка:

`автоматическая загрузка данных → проверка качества → причинный симулятор → baseline X → walk-forward → Champion/Challenger → экспорт .pumpmodel`

## Обязательный старт для AI/Codex

Перед любыми изменениями полностью прочитать:

1. [`ИНСТРУКЦИЯ_1.md`](ИНСТРУКЦИЯ_1.md)
2. [`AGENTS.md`](AGENTS.md)
3. [`docs/project-memory/CURRENT_STATE.md`](docs/project-memory/CURRENT_STATE.md)

Главное техническое задание целиком находится в `ИНСТРУКЦИЯ_1.md`.

## Планируемый результат

- один Windows-установщик `PumpResearchLabSetup.exe`;
- приложение запускается без отдельно установленного Python;
- базы рынка скачиваются и актуализируются кнопками в приложении;
- большие базы хранятся отдельно от EXE в Parquet/DuckDB;
- обучение можно ставить на паузу и продолжать с checkpoint;
- модели сначала работают только в simulation/shadow/paper;
- проверенная модель экспортируется в формат `.pumpmodel` для будущей Android-интеграции.
