# AGENTS.md — обязательные правила проекта Pump.exe

## Перед началом работы

Каждый AI/Codex обязан полностью прочитать:

1. `ИНСТРУКЦИЯ_1.md`;
2. этот файл;
3. `docs/project-memory/CURRENT_STATE.md`;
4. остальные файлы, прямо названные обязательными в инструкции.

До завершения чтения нельзя менять код, структуру или документацию.

## Архитектурные ограничения

- Pump.exe — отдельная Windows research-лаборатория, а не замена Android PUMP.
- Не изменять существующий Android-репозиторий без отдельного задания пользователя.
- Не реализовывать реальные биржевые ордера.
- Сначала simulation, затем shadow, затем paper. Реальная торговля не входит в текущий scope.
- Данные, модели, checkpoints и отчёты не встраивать в один EXE.
- Установщик создаёт каталоги данных; программа сама скачивает и обновляет базы.
- Любой алгоритм обязан быть причинным и не видеть будущие данные.
- `NO_TRADE` — полноценное допустимое действие.
- Ограничения риска обеспечиваются жёсткими action masks, а не только штрафом награды.
- Baseline X нельзя незаметно переписывать. Изменённая версия получает новое имя.
- Все комиссии, spread, slippage, latency и правила исполнения едины для всех кандидатов.

## Порядок разработки

1. Аудит и формализация схемы данных.
2. Минимальный вертикальный путь: импорт/скачивание → валидация → признаки → симулятор → baseline X → отчёт.
3. Доказательство причинности и воспроизводимости.
4. Автоматический Data Manager.
5. Синтетические сценарии.
6. Walk-forward и закрытый holdout.
7. Adaptive Strategy Router.
8. Champion/Challenger.
9. Windows GUI.
10. Упаковка и установщик.
11. Экспорт `.pumpmodel`.

Нельзя начинать тяжёлый RL или косметическую полировку GUI до проверки симулятора.

## Сохранность работы

- Один логический этап — один отдельный commit.
- Не удалять пользовательский функционал ради упрощения интерфейса.
- Не выполнять разрушительные Git-операции.
- Обновлять `docs/project-memory/CURRENT_STATE.md` после каждого завершённого этапа.
- Отрицательные результаты сохранять как исследовательский опыт, а не скрывать.
- Любой опубликованный показатель должен содержать период, набор данных, комиссии и метод исполнения.

## Критерий честности

Красивый результат на обучающем участке не является доказательством. Кандидат рассматривается только после невиданного временного участка, стресс-тестов и сравнения с baseline X и `NO_TRADE`.
